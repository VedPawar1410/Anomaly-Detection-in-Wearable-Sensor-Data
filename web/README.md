# Web frontend

Next.js 16 (App Router, TypeScript, Tailwind) with uPlot charts. Three pages:

| Route | What it does |
|---|---|
| `/` | Live stream from the API's `/ws/stream`: 31 sensors at 100 Hz, detector flags vs injected faults |
| `/upload` | Upload a PAMAP2 `.dat` or CSV to `/detect` and see the flagged readings |
| `/benchmark` | Detector comparison, from `lib/benchmark.json` |

## Run locally

Start the API from the repo root first (`uvicorn api.main:app --port 8000`), then:

```bash
npm install
npm run dev
```

Open http://localhost:3000. To point at another API, copy `.env.example` to `.env.local` and set
`NEXT_PUBLIC_API_URL` (it is baked in at build time).

## Data files

- `lib/benchmark.json` is generated by `python -m wearable_anomaly.export` (repo root). Don't edit it by hand.
- `public/sample_subject108.csv` is 30 s of the demo recording (test subject 108, with injected faults).
